## 1. 哪些必须严格，哪些可以放宽

### 1.1 六条有效性红线

以下要求只要失败，对应结果就不得进入论文；不是“尽量做到”。

| # | 红线 | 执行要求 | 失败动作 |
|---|---|---|---|
| V1 | **论文结果必须联合留出被试与刺激** | 测试被试和测试句子均不进入训练、预处理拟合、probe、阈值或超参选择；测试被试零校准 | 该 run 标记 `INVALID`，修复后重跑 |
| V2 | **\(H\) 不得泄漏目标** | 目标句任意 token、后文、目标表层统计、候选编码、眼动均不得进入 \(H\)；自动断言必须全绿 | 停止 probe，修复构造 |
| V3 | **matched sham 是主对照** | `trial_shuffle`、`time_block_shuffle`、`phase_randomization` 与 real 同结构、参数、步数、优化器和初始化；高斯噪声只能作弱对照 | 不得用弱噪声替代三类强 sham |
| V4 | **统计单位是被试** | 先算逐被试指标，再做 macro、被试级 CI、方向计数和散点；禁止把 trial 当独立样本 | 重算统计；trial 级显著性不得写入论文 |
| V5 | **测试集不参与选择** | 方法、阈值、强简单基线和超参只在训练/验证部分选择；各方法共享候选清单 | 受污染比较作废 |
| V6 | **主张必须打赢对应对照** | “有 EEG 内容”必须对照 language-only \(R_1\)；“ANMA 结构有价值”必须对照 direct \(u^+\) | 打不赢就降级主张，不换指标抢救 |

对应 SPEC：§4.2、§4.3、§5.1–5.2、§5.6、§8.1、附录 F.1–F.4。

### 1.2 可以放宽的项目

| 原 v2 要求 | v3 默认 | 边界 |
|---|---|---|
| P0 完成完整数据卡、11 项审计、全部定义后才能训练 | 先做 3 天工程冒烟；完整审计在纸面级主实验前补齐 | 冒烟数字必须进入 `debug_runs/`，醒目标注 `NON_PAPER` |
| 正式预注册 v1/v2 + 不可改文件 | `run_card.md` 冻结主指标、split、null、候选规则；`decision_log.md` 只追加改动理由 | 论文不得把事后决定写成事先决定 |
| Gate A/B 数值全部通过才可继续 | 数值用于决定主张档位；方向不清时只允许一次限时补跑 | null 无效、泄漏或测试集选择仍是一票否决 |
| 先导每类 sham 两个实现、约 384 次 probe | 先导每类一个实现；只有 null 校准可疑或要写强结论时才加第二实现 | 三种 sham 类型本身不能砍 |
| 最终外层 \(6\times5\)、主表 5 seeds | 默认外层 \(3\times3\) 覆盖全部被试/刺激折，3 seeds；算力充足再升级到 \(6\times5\)、5 seeds | 联合留出原则和全部被试覆盖不能放松 |
| 候选规模 \(10/50/100/200\) 全做 | \(N=50\) 为主；另做一个较大可行规模；其余为升级项 | 负例仍只来自非训练刺激，不能为凑 \(N\) 放宽来源 |
| 第二数据集 + 第二 \(A\) | 都是升级项，不阻塞初稿或投稿 | 未完成就删除跨数据集 / backbone-agnostic 表述 |
| T1–T6、F1–F12 全齐 | 只做“最低论文包”里的表图 | 每个保留主张必须有直接证据载体 |
| 11 项正式查新 + 9 问 reviewer 预演 | 先做核心撞车面快查，投稿前补关键引用与 5 问预演 | 核心 novelty 和先例边界必须核实 |

> 折数从 \(6\times5\) 调到 \(3\times3\) 是对 SPEC §4.2 的执行层覆盖调整，不是把联合留出改成随机切分。每名被试都必须至少作为测试被试出现一次，每个文本折都必须作为测试刺激出现一次。

### 1.3 证据阈值怎样使用

Gate A/B 名称保留，但功能从“项目准入门”改为“写作档位判定”。

| 证据档位 | 结果形态 | 允许写法 |
|---|---|---|
| **A-Strong** | SPEC §7.2 五项均达到，且三类 sham 结论一致 | 可写“在联合留出协议下观察到跨被试可复现的增量 EEG 证据” |
| **A-Limited** | real 相对 sham 方向稳定、未见刺激仍为正，但部分数值阈值未达 | 只写数据集/底座特定的“与增量证据一致”；明确不确定性 |
| **A-Fail** | real 与 sham 无稳定差异，或结论随 sham 翻转 | 不写 EEG 增量结论；保留诊断图，停止堆模块 |
| **B-Strong** | EQ-ANMA 相对 direct \(u^+\) 的逐被试差值和 CI 支持正增益 | ANMA 结构可作为主贡献 |
| **B-Limited** | 点估计为正但不稳定，或结构指标未达 | EQ-ANMA 降为探索性分析，不把结构优势写进标题 |
| **B-Fail** | direct \(u^+\) 持平或更好 | 删除 ANMA 主贡献，改写为 matched-null evidence score / benchmark |

任何 A/B 档位都不能覆盖 V1–V6 的失败。特别是 sham 自检中：A-S1/A-S2 失败先按实现问题处理；A-S3 只说明 sham 强度不齐，此时改用保守的 \(u^{\min}\) 作主分数并如实报告，不必自动判整条路线死亡。

### 2.2 证据升级包：按收益排序

1. 主表 seeds 从 3 补到 5；
2. 外层切分从 \(3\times3\) 补到 \(6\times5\)；
3. 补第二个非同源数据集；
4. 补第二个 \(A\)；
5. 补完整候选规模、非核心消融、协议敏感性和扩展图。

升级项只有在最低论文包已经稳定、预计不影响 11-06 初稿时才启动。任何升级项失败都不回头改最低包的阈值或选择规则。

## 4. P1：信号先导（08-13 ～ 08-28）

只回答：**真 EEG 比打乱 EEG 更能预测文本吗？**

### 4.1 先导配置

- 冻结 \(A\) latent；先做 1 个外层 cell × 内层 \(3\times3\) cross-fitting × 3 seeds。
- 输入臂：real、trial shuffle、time-block shuffle、phase randomization、text-only。
- 同时报 \(u^{\rm OOF}\)、\(u^{\min}\) 和未见刺激上的方向。
- 先看逐被试分布和 sham 稳定性，再计算 SPEC §7.2 的完整数值。
- 如果方向不清，只允许扩到最多 3 个外层 cell 或补一次 seed；补跑时限不超过 2 个工作日。

### 4.2 任务

| ID | 日期 | 任务 | 出口 |
|---|---|---|---|
| P1-1 | 08-13 ～ 08-14 | 建联合留出 pilot split、固定候选列表、冻结 \(H^{\rm full}\)/\(H^{\varnothing}\) | pilot 泄漏断言全绿 |
| P1-2 | 08-17 ～ 08-20 | 训练 real / 3 sham / text-only probes | 运行清单完整，结构匹配 |
| P1-3 | 08-21 ～ 08-24 | 画逐被试 \(u\) 分布，做 A-S1/A-S2/A-S3 和 unseen-text 检查 | 信号图 v1 |
| P1-4 | 08-25 ～ 08-26 | 计算 Gate A 数值、语言混杂检查和 rank stability | A-Strong / Limited / Fail 初判 |
| P1-5 | 08-27 ～ 08-28 | 限时补跑或定案；同步完成 Related Work 骨架 | A 级证据备忘 |

**判断顺序**：

1. sham 是否是有效对照；不是就修实现；
2. real 是否在多数被试上相对三种 sham 右移；
3. 结论在 unseen text 和 phase-only 下是否仍同向；
4. 最后才看 \(\pi_G\)、rank-corr、CI 等具体阈值决定写作档位。

若 A-Fail，不直接切换到一整套 CSPE 主实验。先用最多 2 天检查 split、\(A\) latent 和任务可验证性；仍为负就保留诊断图，停止本周期的方法堆叠。CSPE 只有在现成数据、G2′/G5 existence test 已接近可跑且额外实现不超过 3 天时，才作为单独立项，而不是自动备线。

### 7.1 Reviewer 五问

1. 数字是否来自联合留出被试与刺激，而不是随机切分？
2. real EEG 是否稳定优于三类 matched sham 和 language-only \(R_1\)？
3. \(H\) 是否包含任何目标信息或其他 shortcut？
4. 若声称结构贡献，是否真正优于 direct \(u^+\)？
5. 证据只有单数据集/单底座时，是否删净通用性和“读心/互信息”式过强措辞？

### 7.2 主张—证据缩放

| 想写的主张 | 最低证据 | 缺失时的写法 |
|---|---|---|
| real EEG 有增量信息 | 逐被试 real-vs-sham 图 + unseen-text 同向 + 有效 sham | 只写诊断，不写方法有效 |
| 加权改善检索 | 主表 + 相对 \(A\)/简单基线的逐被试差值 | 只报观察，不作普遍结论 |
| ANMA 结构有独立价值 | 明确打赢 direct \(u^+\) | 结构降为分析，退出标题 |
| 方法不挑数据/底座 | 真正完成第二个非同源数据集 / 第二 \(A\) | 完全删除该句 |

## 9. 超时与砍项规则

当周落后超过 2 个工作日，按以下顺序立刻砍，不等待下一次 review：

1. 第二个 \(A\)；
2. 第二个数据集；
3. 外层 \(6\times5\) 升级，保留 \(3\times3\)；
4. seeds 5 降到 3；
5. 候选规模只留 \(N=50\) 与一个较大可行值；
6. 非核心消融、扩展图和协议对照。

**永不砍**：联合留出、train-only 拟合、三类 matched sham、language-only \(R_1\)、direct \(u^+\)、逐被试结果、共享候选清单、decision log。
